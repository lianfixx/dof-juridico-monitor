# ADR 0003 — Núcleo neutral al proveedor

Estado: Accepted · 2026-10-02

## Decisión
La lógica vive en Markdown/YAML/JSON/Python estándar. Los proveedores solo tienen adaptadores.

## Consecuencia
ChatGPT, Claude, Gemini, Grok u otro agente pueden ejecutar el mismo protocolo sin depender de memoria o servidores de un proveedor específico.
