# Especificación funcional

## Propósito
Monitorear el DOF con rigor profesional y producir una síntesis útil, no un resumen indiscriminado.

## Prioridades
Fiscal; Compliance/PLD-FT; Administrativo; Amparo.

## Adicional
Reformas, decretos, decisiones nacionales e iniciativas del Ejecutivo de alta relevancia jurídica/económica/empresarial/social.

## Periodos
Martes: viernes anterior, lunes anterior, martes actual.
Jueves: miércoles anterior, jueves actual.
Complemento: fin de semana, publicaciones posteriores al corte, fes de erratas/correcciones/republicaciones.

## Doble vía
### A — PDF completo real
Seguir el destino real desde el sitio oficial; jamás adivinar URL. Registrar páginas/rangos y recorrer sin huecos.
### B — índice + publicaciones + colecciones
Si A falla: índice de cada edición + cada publicación ordinaria + búsqueda oficial de avisos, convocatorias, plazas/vacantes y otras colecciones + paginación accesible.

## Cobertura completa al corte
Solo si todas las ediciones están identificadas, una vía cierra el universo, todos los documentos/anexos están íntegros y no hay pendientes materiales.

## Reporte parcial al corte
Cualquier incumplimiento. Debe identificar el hueco concreto.

## Lectura
La profundidad del análisis puede ser proporcional a relevancia; la lectura para certificar cobertura completa no puede ser selectiva.

## Entregables
Despacho: reporte ejecutivo + correo BLUF para revisión humana.
Operador: editable + guía de estudio/control + bitácora + comentario.

## Fuentes
DOF/SIDOF y fuentes oficiales legislativas/administrativas. Fuentes secundarias solo para orientación, nunca para acreditar vigencia o exhaustividad.
