PREPARACIÓN (en toda tarea)
1. Adjunta el repositorio lianfixx/dof-juridico-monitor con add_repo (acceso de lectura), clónalo con `git clone --depth 1` y lee completos SKILL.md, references/box.md, references/sjf-y-distribucion.md, references/desbloqueo.md y docs/QUALITY_GATE.md. La skill prevalece sobre este mensaje.
2. El box de Simular «main» se maneja con las herramientas mcp__box__shell, mcp__box__read_file y mcp__box__write_file (cárgalas con ToolSearch si están diferidas). Si el conector box no está disponible o no responde tras dos intentos, aplica los planes B y C de references/box.md (TinyFish y, si el chat está vinculado, la Mac) y anota en la bitácora qué vía usaste.
3. En el box, ejecuta `cd /workspace/dof && bash bin/arranque.sh`. Si /workspace/dof/bin no existe o le falta un script (el arranque lo dice), vuelve a escribirlo con mcp__box__write_file desde scripts/box/ del repositorio clonado (mismo contenido, mismo nombre) antes de continuar. Si un script del box difiere del repositorio (compara `sha256sum`), el del repositorio manda.
4. Cada llamada a mcp__box__shell tiene un tope de 600 s y, si se rebasa, la sesión del box se reinicia. Por eso las fuentes se bajan en segundo plano: `bash bin/lanzar.sh <modo>` regresa de inmediato y `bash bin/estado.sh <entrega>` informa el avance (código 3 = sigue en curso). Consulta el estado con llamadas cortas cada 2 o 3 minutos y nunca esperes más de 5 minutos dentro de una sola llamada.
5. Los lectores (subagentes) leen directamente del box con mcp__box__read_file por rangos exactos de página, usando <archivo>.paginas.json (linea_ini, linea_fin). En cada página que esté en `paginas_ocr` del inventario (páginas sin texto o con una imagen grande: formatos, tablas o firmas escaneadas), el lector lee además el OCR de esa página en <archivo>.ocr.txt, y la vista de la imagen cuando el OCR dude. Las ediciones con `ya_reportada: true` no se leen ni se reportan: solo prueban la continuidad de números con el cierre anterior. Reparte bloques sin huecos ni solapamientos; cada lector devuelve páginas leídas, última línea citada, notas por publicación (sujetos, plazos, vigencia, transitorios, efectos, relevancia fiscal/PLD/administrativa/amparo) y estado (INTEGRO, PARCIAL). Las notas se guardan en el box con mcp__box__write_file en /workspace/dof/fuentes/<entrega>/notas/<bloque>.md para que la siguiente tarea las encuentre.
6. Escribe cada script largo de Python o Node en un archivo con la herramienta Write y ejecútalo; no metas scripts largos en comandos encadenados. Si una herramienta pide permiso, no esperes: anota el bloqueo y sigue con lo que sí puedas.
7. Registra la hora real de cada consulta a los portales. Si una vía falla, agota A, B y C antes de declarar PARCIAL.
