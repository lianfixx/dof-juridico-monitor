PREPARACIÓN (en toda tarea)

2. El box de Simular «main» se maneja con las herramientas mcp__box__shell, mcp__box__read_file y mcp__box__write_file (cárgalas con ToolSearch si están diferidas). Si el conector box no está disponible o no responde tras dos intentos, aplica los planes B y C de references/box.md (TinyFish y, si el chat está vinculado, la Mac) y anota en la bitácora qué vía usaste.

Las ediciones con `ya_reportada: true` no se leen ni se reportan: solo prueban la continuidad de números con el cierre anterior. Reparte bloques sin huecos ni solapamientos; cada lector devuelve páginas leídas, última línea citada, notas por publicación (sujetos, plazos, vigencia, transitorios, efectos, relevancia fiscal/PLD/administrativa/amparo) y estado (INTEGRO, PARCIAL). Las notas se guardan en el box con mcp__box__write_file en /workspace/dof/fuentes/<entrega>/notas/<bloque>.md para que la siguiente tarea las encuentre.
6. Escribe cada script largo de Python o Node en un archivo con la herramienta Write y ejecútalo; no metas scripts largos en comandos encadenados. Si una herramienta pide permiso, no esperes: anota el bloqueo y sigue con lo que sí puedas.
