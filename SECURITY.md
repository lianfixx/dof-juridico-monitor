# Seguridad

No subir:
- tokens, cookies, contraseñas o credenciales;
- datos personales de clientes;
- expedientes confidenciales;
- estrategia jurídica no pública;
- correos privados o adjuntos del despacho.

Usar variables de entorno para secretos. Mantener ejemplos anonimizados. El repositorio contiene metodología, no datos confidenciales.
